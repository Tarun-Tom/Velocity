## // CORE_MECHANICS
- **Spatial Lens:** Words only activate within a 180px focus radius, synced to the background dot-grid void.
- **Neural Tether:** Background dots break from the grid to orbit the cursor upon proximity, creating a kinetic "leash" effect.
- **Stasis Locking:** Upon activation, word nodes freeze in 2D space to ensure absolute typing stability.
- **Gilding:** Per-character highlighting—converting Bone White "Queue" text into Gold "Archived" text.
- **Session Archive:** Post-game generation of a "Visual Signature" based on the unique mouse-path of the session.
